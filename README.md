# Financial News Summarizer

## Description
This project is an NLP-based application that summarizes financial news articles using extractive summarization.

## Features
- User-friendly GUI using Tkinter
- Extractive summarization using NLP
- Works offline without APIs

## Technologies Used
- Python
- NLTK
- Tkinter

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Download NLTK data:
   python
   import nltk
   nltk.download('punkt')
   nltk.download('stopwords')

3. Run the application:
   python main.py

## Output
The system generates a concise summary of the input financial news.
